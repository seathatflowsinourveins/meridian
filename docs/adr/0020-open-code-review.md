# ADR 0020: open-code-review as a second reviewer, in delegation mode (plan 8.6)
**Status: adopted.** Decided 2026-11-14 by selection, on the owner's instruction to land the ecosystem; no with-and-without run.

**Need:** a review step that cannot skip files and that brings per-language rules; the manifest's "second reviewer with a published benchmark" (layer 6). The cross-family review stays.
**Candidate:** [alibaba/open-code-review](https://github.com/alibaba/open-code-review/tree/v1.13.9) **v1.13.9**, commit `0e9060da66af36a96a15516e76a001953095318b` (2026-11-13, GitHub marks it verified; the annotated tag is not), Apache-2.0, Alibaba; read 2026-11-14: 50k stars, pushed that day.
**Advisories:** [its advisories page](https://github.com/alibaba/open-code-review/security/advisories), read 2026-11-14 through the API: one, GHSA-wwg6-qfxw-xffj (medium, a repository's `rule.json` could read host files into the prompt), fixed in 1.11.1.
**What it installs:** one file, `~/.local/bin/ocr`: the release binary `opencodereview-linux-amd64`, sha256 `2db29498…1d3e` from the release's `sha256sum.txt` (equal to GitHub's digest). Not the npm package, whose wrapper installs the newest release over itself in the background. No plugin: the Claude Code plugin's `delegate-review` command fixes findings by itself and installs `ocr` unpinned. No hook, MCP server or always-on context.
**Mode:** delegation only. `ocr delegate preview --from origin/main --to HEAD --format json` lists the files a review must cover; `ocr delegate rule <paths>` prints the rules for them; the reviewing agent reads the diff and writes the findings. No model provider, key or account; `agents-check` fails if `~/.opencodereview/config.json` exists. Run here in an empty environment with a scratch home: it wrote nothing and only ran git.
**Limits, measured here:** it leaves out file types it does not know (`.md`, systemd units: 12 of 18 files of #29), so its list is a floor, not the review's scope. Its published benchmark (F1 25.1% against 11.6% for Claude Code on the same model, about a ninth of the tokens) was run in its own-model mode, which needs a provider key and is the owner's decision; nothing is claimed for delegation mode.
**Install:** `deploy/wsl/setup.sh ocr` (also in `upkeep`; `drift` watches its releases). **Removal:** `rm ~/.local/bin/ocr`, and its lines in `setup.sh`.
