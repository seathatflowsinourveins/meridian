## Decision

Not adopted. The first condition fails (the arm without also passed 3 of 3); the second fails (CE used 0.6% more median tokens, not 25% fewer); the always-on delta, +2,866 tokens, is over the 2,000 cap. Under the verbatim brief the model never invoked it, so here it only adds its listing to every request. The static evidence agrees: upstream's only with/without, at commits before the pin, puts `lfg` at about 8.5 to 55 times the cost of plain Claude Code with no difference on the one graded outcome. Overlap, as fact: plan (plan mode), work (`/goal`, subagents, Orca), review (`/code-review`, `/simplify`, `/codex:review`), debug (Claude Code itself passed R1 3 of 3 without it; `/codex:rescue` hands a diagnosis to Codex) and capture (auto memory). Its defaults conflict with this stack's rules: run-time `npx` of range-resolved packages that send diffs to another provider, branches and local commits made without asking, tests and `docs/solutions/` written without asking into a public repository, and reads of other runtimes' session transcripts. Nothing changes: no configuration, no allowlist. Not decided here: the same commit's Codex plugin (`.codex-plugin`) and Antigravity package (`.agy`); `/etc/codex/requirements.toml` pins Codex plugins off, and `setup.sh agents-check` fails once `~/.gemini/config/plugins` exists (L600 at `9c5daaa`).
