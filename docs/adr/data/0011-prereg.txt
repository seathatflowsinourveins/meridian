   relative plugin name resolves beside the patch file" [V].

   "DSH_HOME=$EV/dsh-home for every A/B command (profiles, plugin installs, sessions, logs, anonymous
   id all scratch), DSH_AGENTS_HOME=$EV/agents-home (empty), the shared overlay restating the three
   uploads-off rows ... plus DSH_TELEMETRY_DISABLED=1. Its only blocker is the API key."
   Profiles from dsh's headless template, never dsh-tui [M][F]. Overlay last in both arms [M]: uploads

   effort max, sessions and storage in $EV. Before any run, dump both configurations, diff them (only
   the addition's row may differ), and stop unless both show the upload rows off, OpenTelemetry
   DISABLED [M] and tool-plugin-manager disabled [V].

     39cb68ea3241caeececb6db0521a12ea2fa92fee, uv sync --locked.
   - Brief: the ab-tasks.md R1 brief verbatim, except that only meridian/boundary.py may change, with
     its sha256 recorded before the first run; both arms also get the same create_goal line, because
     the gate fires only on update_goal. The exact line and both hashes were to be fixed before the

     a1 b1 b2 a2 a3 b3; 2 more per arm if the arms differ by one success or tie at 2 each. A run whose
