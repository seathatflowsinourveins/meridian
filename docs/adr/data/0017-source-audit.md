## Download and installation surface

The [installer](https://github.com/rtk-ai/rtk/blob/v1.2.0/install.sh) resolves latest unless `RTK_VERSION` is set, downloads a release archive plus `checksums.txt` from GitHub, verifies SHA-256 and archive paths, and moves the executable to `RTK_INSTALL_DIR` (default `~/.local/bin`). It prints a PATH suggestion, does not edit a shell profile, and does not run init. The full Linux archive contains only `rtk`, `LICENSE` and `LICENSE-ENGINE`; no daemon or MCP server is installed by extracting it. This task directly downloaded/extracted it under scratch, never ran the installer, and never put it on the shared PATH.

## Persistent state and network

- Config resolves to `~/.config/rtk/config.toml` on Linux. Reading defaults does not create that file. Tracking is on by default: SQLite command history and token estimates under the local RTK data directory, normally `~/.local/share/rtk/history.db`; configurable/disableable. Recall defaults to SQLite, retaining compressed raw output, capped at 200 entries, 10 MiB each and 30 days; tee files are an alternative. Thus local raw output persistence is material even with telemetry off ([config](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/core/config.rs), [tracking](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/core/tracking.rs), [retriever](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/core/retriever.rs)).
- Optional `RTK_HOOK_AUDIT=1` appends original and rewritten command text to `~/.local/share/rtk/hook-audit.log`; off by default ([audit function](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/hooks/hook_cmd.rs#L626)).
- Network telemetry is **off by default**, and requires both enabled=true and explicit consent=true. A compiled-in `RTK_TELEMETRY_URL` supplies the collector; absent/empty means no sender. Opt-in POST includes random salted device hash, version/OS/arch, command-family counts, estimated savings, failure/recall counters and configuration/activity aggregates, not command arguments or file contents. It is rate-limited to once per 23 hours; local salt/marker files are written. The collector URL is build configuration, not a literal URL guaranteed by source; no secret build token was inspected ([telemetry](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/core/telemetry.rs), [default config](https://github.com/rtk-ai/rtk/blob/v1.2.0/src/core/config.rs)).
- Wrapped programs retain their own network behavior (git fetch, gh, curl, etc.); compression is not network isolation. Installation downloads from GitHub. The separate `rtk-proxy` is a different executable and was neither installed nor run ([installer](https://github.com/rtk-ai/rtk/blob/v1.2.0/install.sh), [workspace boundaries](https://github.com/rtk-ai/rtk/blob/v1.2.0/Cargo.toml)).
