# ADR 0007: openai/plugins, the official Codex plugins (plan 8.6)

**Status: not adopted.** Decided 2026-11-13. This ADR covers 2 additions from one source, as plan 8.6's candidate list names it (`openai/plugins`), and decides each separately: codex-security, on the source at the pin, a policy probe with the plugin itself and three runs of a real task without it (the arm with it could not be built here, so there is no with/without comparison); and the catalogue's superpowers 6.3.0, for which no with/without task was run. Assessed 2026-11-12; an independent re-check on 2026-11-13 ran 51 checks (44 confirmed, 6 corrected, 1 refuted) and agreed with the verdict; later checks at the source revised four of them (C13, C21, C35, C43; `prereg.corrected_since` in the [results file](data/0007-results.json), where the figures below come from unless another file is linked).

## Candidate

[openai/plugins](https://github.com/openai/plugins) at `d420d13051bffe4543ed39e30fa46b87148e47dd` (2026-11-06, "Add AWS Core to curated marketplace (#410)"), `main`'s head on 2026-11-13; no tags or releases, so the commit is the pin. No repository licence (licence endpoint 404, no LICENSE file); the plugins' `license` fields: 37 MIT, 8 Proprietary, 11 none, 6 others. Maintainer: the GitHub organisation `openai`; 310 commits (11 since 2026-08-14), 63 contributors, 46 open pull requests, issues disabled. Read 2026-11-12, re-checked 2026-11-13. Runtime: Codex CLI 0.167.2 (`rust-v0.167.2`, `ce21072`), `gpt-6-astra`, effort high, the same version before and after every run; file:line evidence below is at `ce21072`.

## Decision

codex-security: not adopted, by the pre-registered rule and equally by the assessment's wording: the preconditions fail (the pins are in place; the bundled advisories are neither fixed nor accepted), and D(with), the token ratio and the always-on delta cannot be measured here. Also weighed, as facts: the route follows upstream's head or the ChatGPT backend with no pin; the copy carries upstream's `main` skills under a release number npm never published and a licence field (Proprietary) unlike upstream's (Apache-2.0); it has high-severity bundled advisories, compiles a compressed runtime at start and starts workers that inherit an unsandboxed mode; it would add an estimated 1,293 tokens to every session; the catalogue carries a broker connector. Measuring it would need the `plugins` pin lifted and only its stdio server allowlisted, `apps` kept off, `remote_plugin` off and `[marketplaces] restrict_to_allowed_sources` set so the git catalogue is refused (`with_window` in the results file; untested).

superpowers 6.3.0: not adopted. No with/without task was run for it; it was decided on the same pins, which block it, and the same unpinned route. Overlap, as fact: Codex's subagents and Orca's worktrees do part of what its parallel-agent and worktree skills do; its content is obra/superpowers, which ADR 0005 measured for Claude Code at v7.0.2. Nothing is installed or enabled.
