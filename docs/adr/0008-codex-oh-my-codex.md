## Decision

Not adopted, by the pre-registered rule: both arms passed R1 3 of 3, and the arm with OMX used 104.4 % more total tokens, not 25 % fewer; it handed part of each run to a sub-agent and was not shown to be faster. Its always-on text added 7,611 to 8,075 tokens to a fresh session's first request (M1). The run was in project scope, without its `notify` and with its hooks run by the bypass flag; the rule's result in user scope is unknown. Also weighed, as facts: its always-on `AGENTS.md` opens with "EXECUTE TASKS TO COMPLETION WITHOUT ASKING FOR PERMISSION"; its Stop hook continues a turn ending in a stall phrase even when it asks permission; in user scope its self-written hook trust would let its hooks run beside Orca's without the owner's `/hooks` review (inferred from one hook); its launcher's `--hotswap` rotates auth slots, and its star prompt stars the repository from the account `gh` is signed in to; 184 versions in nine months.
